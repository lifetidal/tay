# Tay 项目 Logo

当前正式 Logo 是 `tay.png`，2026-10-21 经用户确认采用。

- 原始选定稿：`tay-owl-logo-v5.png`。
- 形象：猫头鹰从树丛中探出，伸出一只爪子，带叶细枝轻遮额头。
- 配色：深蓝轮廓、绿色枝叶、橙色眼睛，浅色实底。当前文件不是透明背景。
- 生成方式与提示词：见 [OWL-LOGO-v5-PROMPT.md](OWL-LOGO-v5-PROMPT.md)。
- 原雪鸮破冰图标备份：`tay-owl-ice-original.png`；更早的终端图形保存在 `tay-terminal.png`。

README 展示和 Arch/AUR 打包均引用 `packaging/icons/tay.png`，后续打包会自动使用本版。其他带版本名的图片是设计过程稿。

Arch/AUR 菜单入口使用 `Icon=tay-owl-rounded-v1`，对应 `/usr/share/pixmaps/tay-owl-rounded-v1.png`。保留 `tay.png` 作为兼容路径，避免复用旧图标名称后菜单仍显示旧图。

当前正式 Logo 已替换为 `tay-owl-rounded-v1.png`：原 v5 图案不变，四角使用 23% 半径、4 倍采样抗锯齿的透明圆角。按用户授权使用程序精确裁切，未采用 imagegen 有碎边的草稿。
