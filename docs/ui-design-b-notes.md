# UI 设计 B 实施笔记(2026-11-10)

观感检查轮(PM 视角):审查标签栏/设置面板/主题的显示观感,修复 P1 三项,
引入栏装饰图案系统,并排查动画 CPU。实机 KDE Wayland 4K,截图目检。

## 1. 布局:设计 B(用户拍板)

- 标签 + 新建/设置图标左簇;时钟 + 窗口按钮右锚;**装饰带填中间**,
  随标签数伸缩 —— 全宽窗口不再「左侧一小簇 + 大片空洞」。
- 图案最小宽(波形 12 / 线 4 / 点 6)仅在宽栏计入标签预算,窄栏标签优先;
  收缩预算修正为每标签 = 文字(含 2 列内边距)+ 关闭 3 + 间隙 2。
- 展开栏(3 行)标签文字垂直居中于行 1(与矢量窗口图标对齐);
  默认字号 12 → 13pt(HiDPI 观感)。

## 2. 图案系统 `BarPattern`

- 枚举 `wave` / `line` / `dots` / `none`;Lua `tab_bar.pattern`;
  设置面板「外观」页「栏装饰 ⟳」循环切换,即时生效并持久化。
  **新增图案 = 一个枚举变体 + chrome.rs 一个绘制函数。**
- `wave` = EKG 心电波形:**矢量折线**(tay-render `WaveSeg` + Quad 管线,
  亚格精度,细笔画),`WAVE_KEYS` 11 个关键点定义 P/R/T 波,
  R 峰染主题强调色;16 格/秒连续向左滚动,基线贴栏底,
  振幅随栏高(0.62×行)。
- 动画心跳:唤醒点到期 → `Event::Timer` → 动画图案才 `request_redraw`
  (8fps);窗口隐藏 / 静态图案零唤醒,空闲 0% CPU 目标不变。

## 3. 亮色模式修复(产品反馈)

- 根因:主题切换时 `keep_custom` 把旧深色栏当「用户定制」跨主题保留 →
  亮色终端配黑栏、设置面板深底深字。现主题切换**整体重推导**栏配色
  (仅保留布局字段)并持久化,颜色编辑仍保留定制字段。
- 设置面板底色改从**终端配色**推导,不再依赖可能错配的栏色。

## 4. 设置面板打磨

标题行分隔线、「关闭」钮悬停转危险色、主题瓷砖加光标色圆点、
活动页签圆角芯片 + 强调边(与栏内活动标签同语言)。

## 5. 性能三修(动画 CPU 128% → 0.7% 单核)

1. **toast 过期比较误判**:`mem::take` 后与已清空队列比较长度,
   只要队列非空每轮 AboutToWait 都重绘,与帧回调共振成 ~50Hz 热循环。
2. **波形驱动正路**:render 只由 RedrawRequested 驱动,wake 到期不触发
   渲染(此前动画靠上述副作用在跑)—— 新增 `Event::Timer` 正路。
3. **inotify Access 自激**:读取 config.lua 被 watcher 当作变更事件 →
   「读文件 → 事件 → 再读」无限重载(实测 5 秒 37477 事件);
   watcher 只对内容修改类事件计数与唤醒。
4. 配套优化:**文本状态哈希门控** —— 波形帧内容不变时跳过 4K 全量
   文本重建(仅 quad 层更新),把单帧成本从 ~160ms 压到毫秒级。

## 6. 设计 D:监控波形 + 齿轮右移(2026-11-10)

- **齿轮右移**:设置齿轮随时钟/窗口按钮锚右,左侧仅留新建标签图标;
  装饰带 = 左侧簇与右侧簇之间,随标签数伸缩。
- **监控图案**:`BarPattern::Cpu`(默认)/ `Net` —— 波形从装饰变真监控。
  数据源 `/proc/stat`(聚合占用)与 `/proc/net/dev`(非 lo 收发合计),
  1s 采样、120 样本历史(约 2 分钟)、峰值归一化 + 缓慢衰减(≈4 分钟
  回落一半);隐藏期间缺口以旧值补平。渲染走同一 WaveSeg 矢量管线,
  最新样本贴右缘、8fps 相位插值平滑左移;低/中/高三档着色,
  高值段染强调色。设置面板「栏装饰 ⟳」循环:cpu → net → wave →
  line → dots → none。非动画图案在栏可见时也保 1s 心跳,切到监控
  图案立即有数据(1Hz 唤醒 ≈ 0% CPU)。
- **外观保存保留钉写字段**:`save_appearance_source` 重建 UI 字段区时,
  原文件已钉写的 tab_bar 字段(含手写治愈块/推导值)继续钉写 ——
  此前任何一次外观保存(如改透明度)都会清除治愈块,深色栏复活。
